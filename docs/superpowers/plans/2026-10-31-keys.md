# Keys implementation plan

> For agentic workers: use superpowers:executing-plans; implement and verify each task below.

**Goal:** Offline catalog and assisted identification of edge-cut euro/cabinet keys.
**Architecture:** Canvas contour extraction and measurable profile ranking; account-scoped IndexedDB; native system-camera intent and bundled ML Kit OCR. No cloud, no general vision model yet.
**Spec:** brief-codex-4.md and the scope/contour approach approved in chat. Unusual keys may be cataloged without profile recognition. OCR matches precede contour candidates; every result remains a human decision.
**Constraints:** codex/keys from codex/kalendarz, draft PR to main without merge. Do not change inspekcje/, ppm.js, CI, signing or secrets. Preserve original key photos; compress previews/door photos separately.

- [x] Core: synthetic image tests first; largest-contour detection, PCA alignment, adjustable blade crop, quality checks, normalized profile, bounded shift/scale comparison, top-three ranking and explicit OCR priority. Similarity is not a probability.
- [x] Storage: account boundaries, validated records/media, atomic JSON merge without duplicates, test-outcome counters. Test import twice and failed storage.
- [x] Native: system camera writes a full file through FileProvider; do not use thumbnail result or CameraX. Bundled Latin OCR works offline; decode only a bounded OCR copy. Preserve original capture bytes in IndexedDB.
- [x] UI: Keys tile, catalog/add/edit, per-door photos and locations, guided camera/crop, query/results with key and door thumbnails, full-photo dialog, profile diagnostic and labeled top1/top3 evaluation. Optional second side and a disconnected replaceable local vision adapter.
- [x] Verify: focused Node tests plus a browser synthetic-image flow, existing route regressions, handoff explaining real-key validation and unverified Pixel/native behavior; prepare publication as a draft PR after this commit.

**Review focus:** white-metal reflections and shadows; head-versus-blade crop; tiny keys and scale loss; account switch during async work; low-memory/native cancellation and honest quality/similarity labels. Real accuracy remains unknown until measured on 10 real keys × 3 new captures.
