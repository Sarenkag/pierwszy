# Inspekcje

Aplikacja na telefon do raportów z inspekcji (zdjęcia + checklista → DOCX i PDF).

- Pliki DOCX i PDF powstają w telefonie.
- Wysyłka i zapis idą przez Google Apps Script na koncie właściciela (Gmail + Google Drive).
- `index.html` — strona aplikacji (pobierana przez skrypt przy otwarciu).
- `Code.gs.txt` — wzór skryptu Apps Script (dane obiektu i adresy uzupełnia się w kopii na koncie Google).
