# Moduł `moduly/kafelek`

Wygląd kafelka dla całej apki (Grzegorz 04/11/2026): ikona w kolorowym kwadracie, nazwa, opcjonalny opis i znaczek z liczbą w rogu,
ruch przy naciśnięciu. Kafelki rysują ekrany Ionic + Vue (klasy `.kf`, `.tile`, `.kf-grid`); moduł dokłada tylko ich CSS przy starcie.

Strona: `<script src="moduly/kafelek/kafelek.js"></script>` (inspekcje: `../moduly/kafelek/kafelek.js`).
